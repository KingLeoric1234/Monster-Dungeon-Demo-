\section{Player}

Player is the main character through the whole game.

\subsection{What Can the Player Do?}

Principle: the controls are simple enough for players to get immersed easily.

\begin{itemize}
  \item Move: WASD to move; Shift + direction keys to sprint.
  \item Check details: Q opens a simple stats panel showing ATK (Attack), DEF (Defense), CRT (Critical Chance), SPD (Speed).
  \item ESC opens the Status Panel, where players check their inventory and armor. This panel lets players manage their gear.
  \item T opens the Task Panel, showing the player's unfinished tasks.
  \item Left mouse is the interaction key: attack enemies, open chests, pick up items, and talk to NPCs.
  \item Right mouse cancels an action, or aims the weapon.
  \item E shows the attack range of the weapon you are holding.
  \item P pauses the game.
\end{itemize}

\subsection{Function: Status Panel}

\begin{enumerate}
  \item Animation: panels open and close with sliding animations for a smoother feel.
  \item Description 1: Health Bar --- shows the player's current health.
  \item Description 2: PP Bar --- shows whether the player can hold Shift to sprint.
  \item Description 3: Gold --- spend it on various equipment or other useful items.
  \item Description 4: Armor Column --- where the player equips and manages their gear.
  \item Description 5: Equipment Detail Slots --- players manage these slots to equip or drop their gear.
  \item Description 6: Storage Slots --- players use or clear these slots.
  \item Description 7: Storage Column --- the right panel of the Status Panel, where players manage their gadgets.
  \item Description 8: Empty Hint --- shows ``Empty'' when no item is equipped in a slot.
  \item Description 9: Safe Column --- stores and protects the player's gadgets if the player dies in the dungeon.
\end{enumerate}
